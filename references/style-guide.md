## 风格定位与证据边界

本风格以一个清晰高概念配合强作者视觉、电影摄影或动画镜头语言、紧凑叙事与有余味的结尾。它不是单一外观，而是一套为每个故事建立独立视听系统的方法。

以下规则区分为四层：

- **跨样本不变量**：在不同媒介和题材中可重复观察到的高层规律。
- **条件变量**：根据主题、媒介、叙事视点与情绪切换的规则。
- **偶发细节**：只适合作为某类变体示例，不提升为全局要求。
- **推荐创作策略**：为了提高生成稳定性与叙事统一性而采用，不宣称为跨样本事实。

当前没有足够证据支持具体制作软件、渲染器、精确焦段、固定帧率或统一制作流程；这些维度保持开放。涉及声音与运动的规则主要是可执行创作建议，不伪装成单张静态参考可以证明的事实。

## 跨样本不变量

- 每个短片建立相对独立且内部一致的视听系统，不把所有故事套入同一种外观。
- 视觉形式与本片主题、人物处境或叙事目标具有强耦合，材质、色彩、镜头、运动、场景与声音共同服务同一核心。
- 异常、奇观或概念通过可见后果被表达，而不只依赖解释性对白。
- 角色、场景与道具承担叙事功能；设计选择需要推动冲突、揭示规则或改变观众理解。
- 结尾通常通过画面、动作、声音或母题变化留下第二层意义，但具体形式可以是反转、悲凉、荒诞、哲思、平静或开放。
- 作者性来自规则一致与表达选择，不机械等同于血腥、黑暗、复杂或高密度特效。

## 条件变量、偶发细节与未知项

### 条件变量

- 主媒介可在写实或半写实 CG、风格化 CG、绘画动画、平面动画、微缩/定格感或混合实验影像之间变化。
- 叙事可采用规则升级、观察累积、循环变奏、黑色笑话、寓言压缩、诗性漂流或媒介实验。
- 摄影可纪实克制、主观扭曲、图形化固定、微距观察或持续运动，取决于叙事视点。
- 色彩可服从现实光源、人物心理、图形符号或材质冲突，不设统一综合色。

### 偶发细节

珠宝与湿润表面、泥水与金属、移轴微缩、海滩纪实、单一几何符号、怪异舞蹈、第一视角追逐等均可作为方向示例，但不得默认成为所有项目的稳定规则。只有当上游素材或故事目标支持时才启用。

### 未知项

无法从当前方法资料确定统一的软件、渲染管线、镜头参数、动作帧率、配乐类型、声音制作流程或固定色彩数值。生成时按用户规格和当前媒介需要决定，不补造“官方参数”。

### 推荐创作策略

- 优先建立一个主媒介，再为材质、摄影、运动与声音选择兼容规则，避免无边界平均混合。
- 将故事压缩为“正常状态 + 清晰异常 + 可见后果”，适用于规则驱动型项目；观察型或实验型项目可跳过该公式。
- 为本片建立一条可跨镜头重复的视觉或声音规则，并在结尾改变其意义。
- 写实异常方向可把“80% 真实世界承托 20% 异常元素”作为创作近似，而非测量结论；以可信现实为主体，只让少量关键异常打破现实秩序。

## 分层风格系统

先锁定一个主媒介，再按需选择其余层。Agent 应根据上游文本和参考素材直接推断兼容默认项；只有方向冲突会显著改变结果时才补问。

### 第一层：主媒介

- 写实或半写实 3D CG
- 风格化漫画 CG
- 绘画动画
- 极简平面动画
- 微缩、定格感或档案感影像
- 混合媒介实验影像

### 第二层：渲染与材质

- 接地磨损与可信物理材质
- 华丽、湿润、反射与危险并存的材质冲突
- 笔刷、残缺边缘与非光滑表面
- 几何色块、极少纹理与符号化设计
- 模型尺度、微缩景观与媒介错位

### 第三层：摄影与构图

- 真实电影机逻辑与动机光源
- 主观广角、镜面、畸变和突然焦点转移
- 固定或克制镜头，让画面内部持续变化
- 建筑式构图、大面积留白和图形关系
- 高机位、微距、长距离观察和尺度错位

### 第四层：运动与动画

- 有重量的物理运动、碰撞和环境反馈
- 诱惑与威胁并存的舞蹈、急停、失衡或抽搐
- 笔触、雾、草、影子和光点的持续变化
- 图形对齐、重复、尺度变化与破坏对齐
- 加速、定格、媒介跳变或不匹配运动

### 第五层：叙事与声音

- 规则升级与不可逆选择
- 观察累积与日常化奇观
- 循环变奏与母题重复
- 黑色笑话与尺度疏离
- 诗性漂流、静默或开放余韵

## 六类默认视觉方向

这些方向是便于 Agent 自动推进的组合预设，不代表互斥的客观分类。若上游已明确媒介或局部迁移范围，以用户要求为准。

### 1. 电影级写实 CG

**适用信号：** 战争、生存、怪物、惊悚、硬科幻、灾难、封闭空间、身体危机。

**组合方式：** 写实或半写实 3D CG + 接地磨损材质 + 动机光源 + 有重量运动 + 可信现实中的少量关键异常。

**摄影与运动：** 使用门框、舱壁、走廊、遮挡和浅景深制造压迫。手持、跟拍和低机位用于危机；静止镜头用于判断与背叛。异常先通过声音、遮挡、局部和尺度线索出现，再按叙事需要完整揭示。

**避免：** 无理由蓝橙光、过度洁净、塑料皮肤、所有角色都像同龄模特、异常元素从一开始占满画面。

### 2. 华丽超现实 CG

**适用信号：** 神话、欲望、贪婪、爱、毁灭、寓言、仪式、身体与权力。

**组合方式：** 写实或风格化 CG + 装饰性高密度材质 + 反射与湿润表面 + 极近特写 + 诱惑与威胁并存的运动。

具体材质组合应根据当前故事重新设计；金属、皮肤、水、泥、织物或创伤只作为可选关系，不构成固定配方。

**避免：** 把华丽做成静态时尚画面；装饰只增添漂亮而不表达欲望、代价或危险。

### 3. 风格化漫画 CG

**适用信号：** 都市、追逐、心理、梦境、意识流、迷幻科幻、身份错位。

**组合方式：** 三维空间 + 图形笔刷或绘画式明暗 + 残缺边缘 + 夸张透视 + 主观摄影和心理色彩。

**摄影与运动：** 可使用第一视角、追踪、甩镜、环绕、广角贴近和突然焦点转移。空间和色彩跟随角色心理变化，但保持人物身份和空间轴线可读。

**避免：** 只添加描边或网点；让所有运动变成无重量的高速滑行。

### 4. 绘画动画

**适用信号：** 恐怖、民俗、童话、森林、神秘、梦境、超自然、记忆。

**组合方式：** 绘画动画 + 可见笔触 + 粗糙表面 + 简化细节 + 插画式光线 + 克制摄影。

镜头可保持稳定，让笔触、雾、植被、影子和光点持续变化。模糊形体可以先于清晰实体，重复环境可逐渐产生偏差。

**避免：** 把绘画效果理解为静态滤镜；边缘、笔触和光影在运动中完全不变。

### 5. 极简平面设计

**适用信号：** AI、文明、身份、自我、宇宙、哲学、存在主义、漫长时间。

**组合方式：** 平面动画 + 几何色块 + 极少纹理 + 强轮廓 + 建筑式构图 + 图标化母题。

运动以图形关系、尺度变化、重复、对齐和破坏对齐为主。每个形状和颜色都承担意义，避免过量解释对白。

**避免：** 为科幻感随意加入霓虹线路；元素过多导致母题失焦。

### 6. 实验影像

**适用信号：** 荒诞、灾难、末日、黑色幽默、群像、文明讽刺、尺度错位。

**组合方式：** 微缩、定格感、监控、档案或混合媒介 + 高机位或非常规观察距离 + 速度、尺度或媒介错位。

实验形式必须服务主题。可让动作速度与声音尺度不匹配，或让观看距离削弱个体、放大文明荒诞。

**避免：** 用随机故障、噪点或无动机剪辑代替明确作者意图。

### 诗意写实变体

适用于巨大未知事物、时间流逝、日常化奇观、悲凉和哲思。异常越巨大，摄影越可以平静。使用克制表演、日常行为、比例关系、时间痕迹与留白；它是写实或绘画方向上的条件变体，不单独作为主媒介。

## 形体、材质、光色与场景

### 形体、轮廓与细节

角色轮廓、年龄感、磨损、身体状态和表演节奏服务身份与冲突。各方向按主媒介控制细节密度，不把所有角色同质化为同龄模特。

### 材质、纹理与渲染

材质参与叙事。可信现实使用接地、磨损、体积空气与真实光学；超现实方向通过材质冲突表达诱惑与代价；实验方向通过模型、档案或媒介错位改变观看方式。不得把风格化缩减为描边、网点、模糊、噪点或静态滤镜。

### 色彩关系与光线

使用定性色彩关系，不设 HEX 色板。光源应有动机；写实方向优先采用场景内可解释的光源。超现实方向让反射、湿润表面和高密度装饰同时承载美丽与危险。漫画 CG 可让色彩跟随心理；极简方向让颜色承担符号功能。避免无理由蓝橙光或无主题霓虹。

### 角色、场景与道具

角色设计服务身份与冲突。场景参与压迫、误导、尺度反差或规则揭示。指定道具、文字、品牌元素与空间关系按用户要求保留；姿态、构图与文字是否冻结由 `preserve/change` 决定，不设无条件全局锁定。

## 构图、动作、叙事与声音

### 构图与镜头

根据主媒介选择电影摄影、图形构图或实验观察方式。通过超大全景与极近特写形成景别反差；运镜跟随人物心理和规则升级，不让所有镜头持续运动。非写实媒介不必强行服从物理电影机，但应保持空间关系可读。

### 动作、动画与特效

视频动作写清准备、主要动作、结果、环境响应与收势，呈现速度变化、物理重量及布料、头发、液体或粒子反馈。平面和实验媒介可有意破坏物理运动，但必须说明规则并保持连续。

### 叙事、台词与声音

规则升级型可按异常出现、人物接触、行动建立规则、第一次解决失败、规则变化、局势升级、真相显露、高潮与余韵组织。其他故事可以采用观察累积、循环变奏、黑色笑话、寓言压缩或诗性漂流；不得为了风格擅自增加失败、反转、高潮或不可逆代价。

声音分为近景拟音、环境音景、音乐和沉默。先用拟音与环境建立可信世界，再决定音乐何时进入。规则变化或真相揭示时，可撤去音乐、放大单一声音或制造不自然的静默。

## 连续性与负面约束

锁定用户明确指定的人物身份与数量、关键关系、核心事件、必要对白、品牌元素、指定道具与结局。姿态、文字和构图根据逐图参考职责处理，不默认全部冻结。

批量图与多镜头统一角色、场景、材质、光线、镜头、运动与道具锚点。禁止媒介漂移、身份漂移、塑料皮肤、无重量滑行、随机故障、主题无关装饰，以及只重复气氛却不推进规则、代价或真相。

## 中性方法观察

以下是可迁移的方法簇，不指向任何具体作品、角色或镜头：

- **封闭空间现实主义：** 通过磨损环境、动机光源、空间遮挡与尺度线索，让可信现实承托异常。
- **装饰性身体寓言：** 通过高密度装饰、材质冲突、局部特写和失衡运动，让美丽与危险同时成立。
- **城市主观感知：** 通过镜面、层级空间、夸张透视、焦点转移和心理色彩，让空间成为人物意识的延伸。
- **绘画式未知环境：** 通过可见笔触、重复环境、边缘变化、雾与光点，让画面本身持续产生不确定性。
- **几何哲思寓言：** 通过少量符号、尺度变化、重复与对齐关系承载文明、身份或时间主题。
- **尺度错位讽刺：** 通过微缩、远距离观察、速度与声音不匹配，让严重事件产生荒诞和文明距离感。
- **日常化巨大奇观：** 通过平静摄影、普通行为、时间痕迹与比例关系，把宏大异常转化为悲凉或哲思体验。

执行时选择最相关的一至两组方法，不一次混合全部观察。方法只贡献空间、材质、光源、景别、尺度、运动和情绪关系，不贡献具体角色、地点或标志性构图。
