## 1. 多参考职责与冲突处理

每张参考图使用独立条目：

```yaml
references:
  - id: "ref-01"
    role: "identity | outfit | scene | composition | style | motion | lighting"
    must_take: "必须继承的内容"
    may_take: "可选择继承的内容"
    must_not_take: "不得从该图继承的身份、服装、构图或风格"
    priority: "与其他参考冲突时的优先级"
    conflict_resolution: "冲突时保留谁、舍弃谁以及原因"
```

默认优先级：用户明确文字约束 > 身份与内容参考 > 用户指定保留项 > 构图参考 > 场景参考 > 风格参考 > Agent 创作补充。

风格图只提供线条、材质、光色、渲染或运动语言，不自动提供人物身份、服装、地点和构图。身份图不自动提供姿态和原画风。首帧图在图生视频中默认负责身份、空间与起始状态，除非用户明确允许改变。

## 4. 剧本风格化与文生剧本

### 保留边界

- 保留：{核心因果、人物、关系、必要对白与用户指定结局}
- 可风格化：{高概念强化、视觉母题、场景表达和节奏策略}
- 不得新增：{用户未授权的反转、高潮、失败、牺牲或不可逆代价}

### 叙事结构

从上游内容自行选择，不为普通选择反复补问：

- 规则升级型：异常出现 → 接触 → 失败 → 变化 → 升级 → 真相 → 高潮 → 余韵
- 观察累积型：日常建立 → 多次观察 → 意义偏移 → 平静或悲凉收束
- 循环变奏型：重复行为 → 每轮改变一个条件 → 规则显形 → 循环被打破或继续
- 黑色笑话型：严肃建立 → 视角或尺度错位 → 荒诞后果 → 简短回钩
- 寓言压缩型：符号建立 → 关系对抗 → 代价显现 → 单一意象收束
- 诗性漂流型：感官片段 → 母题回返 → 时间或意识变化 → 开放余韵

`{场次号}｜{内/外景}｜{地点}｜{时间}`

{可拍摄的场景与动作；自然包含概念证据、环境变化和空间关系}

{必要对白}

`镜头：{景别} / {机位} / {焦段倾向} / {运镜} / {焦点变化}`

`视觉：{材质} / {光源} / {色彩关系} / {专属规则}`

`声音：{近景拟音} / {环境音} / {音乐或静默}`

检查每场是否推进规则、关系、代价、观察或主题；删除只重复气氛而没有新信息的场次。

## 5. 分镜、文生视频与图生视频

### 文生视频入口

没有参考图时，根据全局角色、场景、材质、光线和运动锚点生成首镜状态，并让每个镜头的结束状态成为下一镜头的起始状态。

### 图生视频入口

逐张定义身份图、首帧图、场景图、构图图和风格图。默认冻结首帧中的人物身份、数量、空间关系和关键道具；姿态、构图与镜头是否改变由用户要求和 `may_take/must_not_take` 决定。

### 每镜头模板

- 镜头号：{镜头号}
- 参考职责：{逐图 role、must_take、must_not_take 与优先级；无参考图时省略}
- 起始状态：{人物、道具、环境、光线}
- 主体动作：{准备—主要动作—结果—停顿或衔接}
- 环境响应：{场景、道具、布料、头发、液体、粒子、灯光或群演反馈}
- 镜头运动：{景别、机位、路径、速度、动机、焦点变化与结束构图；无运动时写固定镜头}
- 风格保持：{主媒介、形体、材质、光线、动画或摄影规则}
- 声音：{近景拟音、环境音、音乐或静默}
- 转场：{与下一镜头的衔接}
- 结束状态：{下一镜头继承的人物、道具、环境、动作与画面状态}
- 连续性：{身份、服装、道具、空间、光源、时间、运动轨迹、速度变化与物理重量}
- 输出规格：{仅继承用户或上游值}

多镜头输出让视觉母题逐步变化，不让每个镜头重复同一种强度。

## 6. 分层风格控制

不要用单一等级同时改变所有维度。分别判断以下控制项：

```yaml
style_controls:
  visual_authorship: "克制 | 明确 | 强烈"
  medium_experiment: "传统 | 轻度实验 | 强实验"
  narrative_deviation: "忠实保留 | 结构强化 | 大幅重构"
  transformation_range: "局部 | 中等 | 全面"
  adult_content: "仅继承上游要求，不主动提高"
  abstraction: "具象 | 混合 | 抽象"
```

用户未指定时，由 Agent 根据上游素材直接推断：

- 默认忠实保留核心因果、身份和关系。
- 默认使用“明确”的视觉作者性与“轻度实验”的媒介策略。
- 默认只进行结构强化，不擅自大幅重构叙事。
- 成人内容强度只继承用户或原始素材，不因追求作者性而自动增加。
- 纯图像任务不主动改变叙事结构；局部迁移任务冻结未被要求改变的维度。

只有两个候选会造成身份、因果或成片类型显著相反且上下文无法判断时，才向用户补问。

## 7. 连续性与负面提示词

```yaml
continuity_lock:
  character_anchor: "{身份、轮廓、年龄感、服装、身体状态与关系}"
  scene_anchor: "{空间布局、尺度、时间与环境状态}"
  material_anchor: "{角色、服装、道具与场景的材质规则}"
  light_anchor: "{动机光源、方向、明暗关系与综合色倾向}"
  camera_anchor: "{景别、机位、空间轴线、焦段感与构图关系}"
  motion_anchor: "{动作节拍、重量、轨迹与环境响应}"
  prop_anchor: "{关键道具、文字、品牌元素与状态}"
```

排除：{与主媒介冲突的媒介漂移}、{材质漂移}、{比例与身份漂移}、重复人物、未经允许改变构图、连续性断裂、运动融化、无关 UI、无动机蓝橙光、塑料皮肤、无重量高速滑行、主题无关装饰或随机故障。只保留与当前任务相关的偏移项。
